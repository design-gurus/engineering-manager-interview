# Rounds

Each page explains one round of the engineering manager loop: what the interviewer is measuring, how the time is spent, and what a strong answer contains. Start with the loop overview if you have not seen the whole process yet.

| Page | Round length | What it measures |
|---|---|---|
| [The interview loop](interview-loop.md) | Whole process | The order of stages and what each one decides |
| [People management](people-management.md) | 45 to 60 minutes | Decisions about performance, hiring, delegation, and growth |
| [Project retrospective](project-retrospective.md) | 60 minutes | Ownership and depth on one past project |
| [System design for managers](system-design-for-managers.md) | 45 to 60 minutes | Technical judgment, trade-offs, and delivery planning |
| [Behavioral](behavioral.md) | 45 minutes | Past behavior under pressure, failure, and disagreement |
| [Situational](situational.md) | 30 to 45 minutes | Judgment in a hypothetical situation |
| [Coding](coding.md) | 45 minutes | Whether the manager can still read and write code |

For the questions asked in each round, see the [question bank](../questions/README.md). For full lessons on every round, see [Grokking the Engineering Manager Interview](https://www.designgurus.io/course/grokking-the-engineering-manager-interview?utm_source=github&utm_medium=repo&utm_campaign=engineering-manager-interview&utm_content=rounds-readme).
