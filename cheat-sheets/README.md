# Cheat Sheets

One-page references for preparing the engineering manager interview. Each sheet can be read in about five minutes.

| Page | Use it when |
|---|---|
| [Engineer and manager roles compared](ic-vs-manager.md) | You are moving from an individual contributor role to a first manager role |
| [Story bank](story-bank.md) | You need to choose and organize the stories you will tell |
| [STAR for managers](star-for-managers.md) | Your answers are long, or they sound like an engineer's answers |
| [Questions to ask the interviewer](questions-to-ask-the-interviewer.md) | You reach the last five minutes of a round |
| [Red flags](red-flags.md) | You want to review your answers for patterns that cause a rejection |
| [Four-week plan](four-week-plan.md) | You have an interview date and need a schedule |

For full lessons and worked answers, see [Grokking the Engineering Manager Interview](https://www.designgurus.io/course/grokking-the-engineering-manager-interview?utm_source=github&utm_medium=repo&utm_campaign=engineering-manager-interview&utm_content=cheat-sheets-readme).
