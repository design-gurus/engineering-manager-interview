# Question Bank

About 70 engineering manager interview questions, grouped by the round in which they are asked. Each group states what the interviewer is measuring, so that you can prepare one story per group instead of one answer per question.

| Page | Questions | Asked in |
|---|---|---|
| [People management questions](people-management-questions.md) | 20 | People management round, hiring manager screen |
| [Behavioral questions](behavioral-questions.md) | 18 | Behavioral round |
| [Situational questions](situational-questions.md) | 16 | Situational round, cross-functional round |
| [Project and delivery questions](project-and-delivery-questions.md) | 18 | Project retrospective, hiring manager screen |

## How to use the bank

1. Read one page and mark the questions you could not answer with a real case.
2. Add a story for each gap to your [story bank](../cheat-sheets/story-bank.md).
3. Answer five questions aloud with a timer set to three minutes each.
4. Check each answer against [STAR for managers](../cheat-sheets/star-for-managers.md).

These pages list questions only. Worked answers for the most common ones are in [Grokking the Engineering Manager Interview](https://www.designgurus.io/course/grokking-the-engineering-manager-interview?utm_source=github&utm_medium=repo&utm_campaign=engineering-manager-interview&utm_content=questions-readme).
